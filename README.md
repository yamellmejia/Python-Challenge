# Python-Challenge

The following project and repository analyze the data from a "PyBank" CSV containing financial data and a "PyPoll" CSV containing election data. The project is split into two sections for each CSV, reading through its data and focusing on certain topics. 

The PyBank section retrieved the following data from the CSV and placed the results in a text file placed into an "Analysis" folder. The data includes:

- The total number of months included in the dataset
- The net total amount of "Profit/Losses"
- The average of the changes in the "Profit/Losses"
- The greatest increase in profits, including the date and amount
- The greatest decrease in profits, including the date and amount

The PyPolll section also reads through the data set to show the following data:

- The total number of votes cast
- A list of candidates who received votes
- The percentage of votes each candidate won
- The total number of votes each candidate won
- The winner of the election based on popular vote

The code used to retrieve these results can be found in the Resources folder of each section. The results are printed in each designated Analysis folder.

The code for both sections of the project had a "starter code" that offered a layout of how the code should look and what should be included. The rest of the code was created using the assistance of past assignments, online resources, and artificial intelligence. The use of AI was mainly for suggestions on structuring the code or finding ways to solve errors or bugs within the code. 

This project showcased the importance of Python in data analysis. In this project, the limitations of Excel-based analysis are clear as such large datasets would have been much more difficult to analyze on that platform.
